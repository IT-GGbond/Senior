# 银龄配办小程序 — 前后端接口文档

> **Base URL**: `https://frp-six.com:63466/`  
> **认证方式**: 请求头携带 `Authorization: Bearer <token>`（登录/注册接口除外）  
> **统一响应格式**:

```json
{
  "code": 0,          // 0=成功，非0=失败（见错误码表）
  "data": {},          // 业务数据
  "message": "ok"      // 提示信息
}
```

**错误码表**:

| code  | 含义         |
|-------|------------|
| 0     | 成功         |
| 40000 | 请求参数错误 |
| 40100 | 未登录       |
| 40101 | 无权限       |
| 40300 | 禁止访问     |
| 40400 | 数据不存在   |
| 50000 | 系统内部异常 |
| 50001 | 操作失败     |

**角色枚举**:

| 值         | 含义   |
|-----------|--------|
| ELDERLY   | 老人   |
| FAMILY    | 家属   |
| VOLUNTEER | 志愿者 |
| ADMIN     | 管理员 |

**任务状态枚举**:

| 值          | 含义   |
|------------|--------|
| PENDING    | 待办   |
| IN_PROGRESS| 进行中 |
| COMPLETED  | 已完成 |
| CANCELLED  | 已取消 |

**求助状态枚举**:

| 值          | 含义       |
|------------|----------|
| WAITING    | 待接单     |
| ACCEPTED   | 已接单     |
| IN_SERVICE | 服务中     |
| COMPLETED  | 已完成     |
| CANCELLED  | 已取消     |

**业务分类枚举**:

| 值          | 含义     |
|------------|---------|
| GOVERNMENT | 政务帮办 |
| LIFE       | 生活协助 |
| HEALTH     | 健康支持 |
| COMMUNITY  | 社区连接 |

## 一、用户模块 `/api/user`

### 1.1 微信登录

- **POST** `/api/user/login`
- **权限**: 无需登录

**请求体 (LoginDTO)**:

| 字段 | 类型   | 必填 | 说明                                    |
|------|--------|------|-----------------------------------------|
| code | String | 是   | 微信 `wx.login()` 返回的 code（Mock模式下直接当openid使用） |

**响应体 (LoginVO)**:

| 字段       | 类型    | 说明                                   |
|------------|---------|----------------------------------------|
| registered | boolean | 是否已注册。false=需跳转注册页          |
| token      | String  | JWT令牌（已注册时返回，未注册时为null）  |
| userInfo   | UserVO  | 用户信息（已注册时返回，未注册时为null） |

**示例**:
```json
// 请求
{ "code": "mock_openid_001" }

// 响应 - 已注册
{
  "code": 0,
  "data": {
    "registered": true,
    "token": "eyJhbGciOi...",
    "userInfo": {
      "id": 1,
      "openid": "mock_openid_001",
      "nickname": "张大爷",
      "avatarUrl": null,
      "name": "张三",
      "phone": "13800138000",
      "community": "阳光社区",
      "inviteCode": "A3B5C7",
      "roles": ["ELDERLY"]
    }
  },
  "message": "ok"
}

// 响应 - 未注册
{
  "code": 0,
  "data": { "registered": false, "token": null, "userInfo": null },
  "message": "ok"
}
```

## 三、任务模块 `/api/task`

### 3.1 创建任务

- **POST** `/api/task`
- **权限**: `ELDERLY` / `FAMILY`

**请求体 (TaskCreateDTO)**:

| 字段       | 类型       | 必填 | 说明                                        |
|------------|-----------|------|---------------------------------------------|
| title      | String    | 是   | 任务标题                                    |
| category   | String    | 否   | 分类：GOVERNMENT/LIFE/HEALTH/COMMUNITY      |
| planDate   | String    | 否   | 计划日期，格式 `yyyy-MM-dd`                 |
| planTime   | String    | 否   | 计划时间，如 `09:00`                        |
| location   | String    | 否   | 办事地点                                    |
| remark     | String    | 否   | 备注                                        |
| elderlyId  | Long      | 否   | 老人ID（家属代建时必填，老人自建时自动填充） |
| templateId | Long      | 否   | 关联模板ID（选模板时填，自动复制模板步骤和材料） |
| steps      | StepDTO[] | 否   | 手动添加的步骤（不用模板时）                |
| materials  | String[]  | 否   | 手动添加的材料名称列表（不用模板时）        |

**StepDTO**:

| 字段        | 类型    | 说明     |
|-------------|---------|---------|
| sortOrder   | Integer | 步骤序号 |
| title       | String  | 步骤标题 |
| description | String  | 步骤说明 |

**响应体 (TaskVO)**:

| 字段        | 类型           | 说明                     |
|-------------|---------------|--------------------------|
| id          | Long          | 任务ID                   |
| title       | String        | 任务标题                 |
| category    | String        | 分类                     |
| planDate    | Date          | 计划日期                 |
| planTime    | String        | 计划时间                 |
| location    | String        | 办事地点                 |
| remark      | String        | 备注                     |
| status      | String        | 状态：PENDING/IN_PROGRESS/COMPLETED/CANCELLED |
| elderlyId   | Long          | 所属老人ID               |
| elderlyName | String        | 老人姓名                 |
| creatorId   | Long          | 创建者ID                 |
| templateId  | Long          | 关联模板ID               |
| createTime  | Date          | 创建时间                 |
| updateTime  | Date          | 更新时间                 |
| steps       | TaskStep[]    | 步骤列表                 |
| materials   | TaskMaterial[]| 材料清单                 |

**TaskStep 子对象**:

| 字段        | 类型    | 说明                  |
|-------------|---------|----------------------|
| id          | Long    | 步骤ID               |
| taskId      | Long    | 所属任务ID           |
| sortOrder   | Integer | 步骤序号             |
| title       | String  | 步骤标题             |
| description | String  | 步骤说明             |
| isCompleted | Integer | 是否完成（0=否 1=是）|

**TaskMaterial 子对象**:

| 字段      | 类型    | 说明                    |
|-----------|---------|------------------------|
| id        | Long    | 材料ID                 |
| taskId    | Long    | 所属任务ID             |
| name      | String  | 材料名称               |
| isChecked | Integer | 是否已勾选（0=否 1=是）|

## 附：前端对接要点

### Token 携带方式

每次请求（除登录/注册外）在 Header 中携带：
```
Authorization: Bearer eyJhbGciOi...
```

微信小程序示例：
```javascript
wx.request({
  url: 'http://localhost:8080/api/user/info',
  header: {
    'Authorization': 'Bearer ' + wx.getStorageSync('token')
  },
  success(res) {
    if (res.data.code === 0) {
      // 业务数据在 res.data.data
    } else {
      // 错误处理，参考错误码表
    }
  }
})
```

### 日期格式

所有 Date 类型字段返回格式为 **ISO 时间戳**（如 `"2026-04-27T08:30:00.000+00:00"`），前端可直接用 `new Date()` 解析。
