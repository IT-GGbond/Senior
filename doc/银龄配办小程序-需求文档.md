> **版本**：v2.0  
> **日期**：2026年5月  
> **项目类型**：《软件开发综合实践》课程项目  
> **团队**：第3组（魏良铠、梁艺敏、付世帆、罗乐凡、林泽坤）

## 核心功能

1. 用户注册登录（手机号或账号密码 + 角色选择）
2. 家属绑定老人（邀请码）
3. 任务创建与分类管理（含四大模块分类）
4. 任务状态流转（待办→进行中→已完成/已取消）
5. 办事步骤管理（创建/展示/逐步勾选）
6. 材料清单管理（创建/展示/勾选确认）
7. 家属代建任务、查看进度
8. 一键求助（老人发起）
9. 志愿者接单
10. 服务记录（时长、方式、内容）
11. 老人端适老化界面

## 一、项目概述

### 1.1 项目定位

银龄配办是一款面向老年人的**生活事务辅助与社区互助移动端H5网页**，聚焦老年人日常办事场景（复诊、社保、缴费、证件更新等），提供全流程配套式服务。

**不是**大而全的养老平台，**而是**精准聚焦"老人办事"这一个场景的精细化工具。

### 1.2 核心理念

```
要办事 → 提醒你 → 告诉你带啥 → 教你怎么走 → 卡住了帮你叫人 → 办完了打勾
```

### 1.3 产品形态

- **前端**：移动端 H5 网页（适配移动端分辨率，类似 App 体验）
- **后端**：Spring Boot + MySQL
- **要求**：完整可运行的前后端系统



## 二、用户角色

系统有 **4种用户角色**，一个用户可以**同时拥有多个角色**（如家属同时也是志愿者）。

### 2.1 角色一览

| 角色       | 说明                         | 核心操作                                     |
| ---------- | ---------------------------- | -------------------------------------------- |
| **老人**   | 服务对象，使用极简界面       | 查看今日任务、勾选材料、一键求助             |
| **家属**   | 老人的子女/亲属，远程协助    | 绑定老人、代建任务、编写步骤、设提醒         |
| **志愿者** | 社区志愿服务者，任何人可注册 | 查看求助、接单、记录服务、查看积分           |
| **管理员** | 社区工作人员，后台管理       | 审核求助、管理志愿者、创建流程模板、查看统计 |

### 2.2 角色关系

```
家属 ←→ 老人：多对多（一个家属可绑定多个老人，一个老人可绑定多个家属）
老人 → 志愿者：老人发求助，志愿者接单
管理员：管理全局数据和流程模板
```

### 2.3 用户注册与登录

- 所有用户通过**手机号注册/登录**或**账号密码登录**
- 首次登录后选择角色（可多选）
- 选择"老人"角色时需填写：姓名、手机号、所在社区
- 选择"家属"角色时需填写：姓名、手机号、与老人的关系
- 选择"志愿者"角色时需填写：姓名、手机号、所在社区（**无需审核，任何人可注册**）
- 管理员角色由**系统预置**，不开放注册

### 2.4 家属绑定老人

- 绑定方式：**邀请码**（实现最简单）
- 流程：老人注册后系统生成唯一邀请码 → 家属输入邀请码完成绑定
- 支持多对多：一个老人可被多个家属绑定，一个家属可绑定多个老人

## 三、业务分类（四大模块）

业务按场景分为四大模块，用于任务创建时的分类选择：

| 模块         | 典型事务举例                                            |
| ------------ | ------------------------------------------------------- |
| **政务帮办** | 社保认证、证件更新（身份证/户口本）、补贴申领、政策咨询 |
| **生活协助** | 水电燃气缴费、银行业务、手机业务办理、物业相关          |
| **健康支持** | 医院复诊、慢病取药、体检预约、用药提醒                  |
| **社区连接** | 社区活动报名、邻里互助、社区服务咨询                    |

> 说明：四大模块是**业务分类维度**，用于任务归类和首页分类展示。下面的六大功能是**功能模块维度**，是系统的核心能力。

## 四、功能需求（六大功能模块）

### 4.1 事务创建与分类管理

#### 4.1.1 创建任务

| 字段         | 说明                                | 是否必填 |
| ------------ | ----------------------------------- | :------: |
| 任务标题     | 如"去医院复诊"                      |    是    |
| 所属模块     | 政务帮办/生活协助/健康支持/社区连接 |    是    |
| 预计办理日期 | 日期选择器                          |    是    |
| 预计办理时间 | 时间选择器                          |    否    |
| 办理地点     | 文字输入，如"市一医院3楼"           |    否    |
| 备注         | 补充说明                            |    否    |

- **创建人**：老人本人 或 家属代建
- 家属代建时需选择为哪位绑定老人创建

#### 4.1.2 任务分类展示

任务按状态自动分为三类：

| 分类         | 规则                          |
| ------------ | ----------------------------- |
| **今日事项** | 办理日期 = 今天，且未完成     |
| **近期事项** | 办理日期在未来7天内，且未完成 |
| **已完成**   | 已标记为完成的任务            |

#### 4.1.3 任务状态流转

```
待办 → 进行中 → 已完成
              ↘ 已取消
```

- 老人可将任务标记为"进行中"（表示正在办）
- 老人可将任务标记为"已完成"或"已取消"
- 家属可远程查看老人的任务进度

---

### 4.2 办事流程分步引导

#### 4.2.1 流程模板

- 模板由**管理员**或**家属**创建
- 每个模板包含：模板名称、所属模块、步骤列表
- 步骤列表为有序步骤，每步包含：步骤名称、步骤说明

**模板示例：**

> **模板名称**：医院复诊流程  
> **所属模块**：健康支持  
> **步骤**：  
> ① 到医院门诊大厅 → 找到自助机或挂号窗口  
> ② 挂号 → 出示医保卡，选择科室和医生  
> ③ 候诊 → 去对应科室门口等叫号  
> ④ 就诊 → 进诊室，把上次病历和检查报告给医生看  
> ⑤ 缴费取药 → 拿处方去缴费窗口，再去药房取药

#### 4.2.2 任务绑定流程

- 创建任务时可选择绑定一个流程模板
- 也可以不绑定模板，手动为任务添加步骤
- 老人办事时，按步骤逐步勾选完成

#### 4.2.3 老人端步骤展示

- 大字体、大间距展示当前步骤
- 每完成一步打勾，自动展示下一步
- 已完成步骤灰显，当前步骤高亮

---

### 4.3 材料与物品清单提醒

#### 4.3.1 清单内容

每个任务可绑定一个材料清单，清单项包含：

| 字段       | 说明                             |
| ---------- | -------------------------------- |
| 材料名称   | 如"身份证"、"医保卡"、"上次病历" |
| 是否已准备 | 勾选框，老人出门前逐项确认       |

#### 4.3.2 清单来源

- 流程模板可预设默认材料清单
- 家属可为任务手动添加/修改材料清单
- 管理员创建模板时可预设清单

#### 4.3.3 清单使用

- 任务办理日当天，老人进入任务详情可看到清单
- 逐项勾选确认"已带"
- 家属端可查看老人是否已完成材料确认

---

### 4.4 家属远程协助

#### 4.4.1 家属端核心功能

| 功能     | 说明                                               |
| -------- | -------------------------------------------------- |
| 绑定老人 | 通过邀请码绑定，支持绑定多个老人                   |
| 代建任务 | 为老人创建任务，老人端自动显示                     |
| 编写步骤 | 为任务添加/编辑办事步骤                            |
| 设置清单 | 为任务添加/编辑材料清单                            |
| 查看进度 | 实时查看老人的任务进度、步骤完成情况、材料确认情况 |
| 查看求助 | 查看老人是否发起了求助及处理状态                   |

#### 4.4.2 老人端展示原则

- 老人端只展示**最简操作界面**
- 大字体、大按钮、少层级
- 核心操作：看任务 → 勾清单 → 走步骤 → 一键求助 → 标完成

---

### 4.5 社区实时人工求助

#### 4.5.1 发起求助

- **谁能发**：老人（一键求助按钮，大且醒目）
- **求助信息**：
  - 自动关联当前正在进行的任务
  - 老人描述问题（文字输入，可选）
  - 老人所在位置（文字输入，如"市一医院门诊大厅"）
  - 老人联系电话（自动填充注册手机号）

#### 4.5.2 志愿者响应

- 志愿者端可看到**待接单的求助列表**
- 求助信息包含：老人姓名、问题描述、位置、联系电话
- 志愿者点击"接单"后，获取老人电话号码
- **双方通过电话沟通**（线上指导或约定线下见面协助）

#### 4.5.3 求助状态流转

```
待接单 → 已接单（志愿者已响应）→ 服务中 → 已完成
                                           ↘ 已取消
```

#### 4.5.4 求助通知

- 求助发出后，该社区的志愿者在系统中收到提醒（进入H5网页时可见或页面内轮询通知）
- 绑定的家属可在家属端看到老人发起了求助

---

### 4.6 志愿者接单与服务记录

#### 4.6.1 志愿者接单

| 功能         | 说明                                              |
| ------------ | ------------------------------------------------- |
| 查看求助列表 | 按社区筛选，显示待接单的求助                      |
| 接单         | 点击接单，获取老人联系方式                        |
| 记录服务     | 填写服务方式（线上/线下）、服务时长、服务内容摘要 |
| 完成服务     | 标记求助已完成                                    |

#### 4.6.2 志愿激励体系

| 功能     | 说明                                                 |
| -------- | ---------------------------------------------------- |
| 时长累计 | 自动累计志愿服务总时长                               |
| 积分记录 | 每次服务获得积分（1小时 = 1积分）                    |
| 服务评价 | 老人/家属对本次服务打分（1-5星）+ 评语（可选）       |
| 服务证明 | 志愿者可生成志愿服务证明（含姓名、总时长、服务次数） |

#### 4.6.3 志愿者个人中心

- 我的接单记录
- 累计服务时长 / 积分
- 收到的评价
- 生成/下载服务证明

## 五、各角色页面结构

### 5.1 老人端页面

```
老人端
├── 首页（今日事项 + 四大模块入口）
│   ├── 今日事项卡片（大字、醒目）
│   └── 快捷入口：政务帮办 / 生活协助 / 健康支持 / 社区连接
├── 任务详情页
│   ├── 任务信息
│   ├── 材料清单（勾选确认）
│   ├── 办事步骤（逐步勾选）
│   └── 一键求助按钮（大红按钮，固定底部）
├── 我的求助页（查看求助状态）
└── 个人中心
    ├── 我的信息
    ├── 我的邀请码（给家属扫）
    └── 近期事项 / 已完成事项
```

### 5.2 家属端页面

```
家属端
├── 首页（绑定的老人列表）
│   └── 点击某个老人 → 查看其任务列表
├── 任务管理
│   ├── 为老人创建任务
│   ├── 编辑任务步骤
│   ├── 编辑材料清单
│   └── 查看任务进度
├── 求助查看（老人的求助状态）
├── 绑定老人（输入邀请码）
└── 个人中心
```

### 5.3 志愿者端页面

```
志愿者端
├── 求助大厅（按社区筛选的待接单求助）
├── 我的接单
│   ├── 进行中的服务
│   └── 已完成的服务
├── 服务记录（填写服务详情）
└── 个人中心
    ├── 累计时长 / 积分
    ├── 收到的评价
    └── 生成服务证明
```

### 5.4 管理员端页面

```
管理员端
├── 数据概览（用户数、任务数、求助数、志愿服务时长）
├── 流程模板管理
│   ├── 创建模板（名称、步骤、默认材料清单）
│   └── 编辑 / 删除模板
├── 求助管理（查看所有求助及处理状态）
├── 用户管理（查看老人、家属、志愿者列表）
└── 志愿者管理（查看志愿者服务记录、时长统计）
```

## 六、适老化设计规范

### 6.1 交互原则

| 原则         | 具体要求                               |
| ------------ | -------------------------------------- |
| **大字体**   | 老人端正文不小于 18px，标题不小于 24px |
| **大按钮**   | 可点击区域不小于 44×44px，关键按钮更大 |
| **高对比度** | 文字与背景对比度不低于 4.5:1           |
| **少层级**   | 老人端页面层级不超过 3 级              |
| **少输入**   | 尽量用选择代替输入，减少老人打字       |
| **明确反馈** | 每次操作都有明确的成功/失败提示        |

### 6.2 配色建议

| 用途     | 颜色           | 说明             |
| -------- | -------------- | ---------------- |
| 主色     | 暖橙色 #FF8C00 | 温暖、亲切、适老 |
| 辅色     | 深蓝 #2C5F8A   | 信任、稳重       |
| 求助按钮 | 红色 #E53935   | 醒目、紧急       |
| 完成状态 | 绿色 #43A047   | 正向反馈         |
| 背景     | 浅暖灰 #F9F5F0 | 柔和不刺眼       |
